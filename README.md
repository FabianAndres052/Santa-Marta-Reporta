# Santa Marta Reporta — Proyecto académico

Sitio web responsive desarrollado a partir de la plantilla **Paradigm Shift de HTML5 UP**.

## Contenido incluido
- 5+ secciones de contenido.
- 6 imágenes locales en formato SVG.
- 2 videos embebidos de YouTube.
- 1 audio local.
- 1 GIF animado local.
- 1 infografía local en SVG.
- 3 archivos JavaScript con funcionalidades diferentes.
- Formulario de reporte con validación.
- Contador persistente mediante `localStorage`.
- Filtro de categorías.
- Diseño responsive.
- Meta título y descripción para SEO básico.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube **todo el contenido de este ZIP**, no el ZIP como archivo.
3. Entra a `Settings > Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere la URL.

## Nota
El formulario es una demostración académica y no envía información a un servidor.
